A clearer menu bar app. The widget shows what needs attention first and lists at most three linked apps per library, with a search for linking more. The window keeps each page's header in place while the content scrolls, shows linked and available apps as rows with a status and a count, and has a filter in the sidebar. Sheets and the failures window use the same icons, colours and error messages.
